# 最佳实践

## Dark Mode 设计原则

1. **避免纯黑背景** - 使用 `#0D0D0E` 而非 `#000000`，更易阅读
2. **降低白色文本对比度** - 主文本使用 `#FFFFFF`，次要文本使用 `#A0A0A0`
3. **使用透明度** - 边框和分隔线使用 `rgba(255,255,255,0.1)`

## 可访问性 (Accessibility)

- 保持 4.5:1 以上的颜色对比度
- 所有交互元素都应有 `:focus` 状态
- 使用语义化 HTML 标签
- 为图片添加 `alt` 属性

## 性能优化

- 使用 `preconnect` 预加载字体
- 压缩 CSS/JS 文件用于生产环境
- 使用 `loading="lazy"` 延迟加载图片

## 响应式设计

| 断点 | 典型设备 |
|------|----------|
| < 576px | 手机 |
| 576-767px | 大屏手机/小平板 |
| 768-991px | 平板 |
| 992-1199px | 桌面 |
| ≥ 1200px | 大屏桌面 |
